# The browser tests the release gate runs every time (`scripts/dev/gate.sh smoke`); the full browser run (`gate.sh browser`)
# is for changes to the engine and runs less often. One entry per line: `file.py` is the whole file, `file.py::text` the tests
# whose name contains the text. Nothing here is removed from the full run, and a guard is never dropped to make this fast.
#
# What belongs here: every test that guards a duplicate or uncertain send, consent, mail or the truthfulness of an answer, and
# one or two tests per platform family and per kind of widget, so that a change to the engine that breaks a whole family shows.
# Keep it under about five minutes on an idle machine: `gate.sh smoke` prints its slowest tests; move a slow file out and name a
# faster one for the same guard rather than letting the gate grow.
