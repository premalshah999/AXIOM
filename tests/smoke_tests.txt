# What `scripts/dev/gate.sh smoke` runs, with a browser or without one: one command that asks whether a change broke a guard or a
# whole flow. It is not part of `gate.sh release` until it has had one clean run on a quiet Mac. The full browser run (`gate.sh browser`)
# is for changes to the engine and runs less often.
#
# One entry per line: `file.py` is the whole file, `file.py::text` the tests whose name contains the text. Nothing here is removed
# from the fast, gallery or full runs, and a guard is never dropped to make this fast. An entry that names no test is printed at the
# end of the run: a renamed guard must not leave quietly.
#
# What belongs here: every test that guards a duplicate or uncertain send, a wrong job, consent, a mail mix-up, a false confirmation
# or the truthfulness of an answer; the mail, gallery and Aggressive flows; and one or two tests per platform family and per kind of
# widget, so that a change to the engine that breaks a whole family shows. `gate.sh smoke` prints its slowest tests: move a slow
# file out and name a faster one for the same guard rather than letting the gate grow.
