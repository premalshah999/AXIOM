# ApplyPilot

A self-hosted workspace for discovering suitable jobs and managing evidence-backed applications with six normal browser owners and two specialists.

See [the developer guide](DEVELOPER.md) for setup, architecture, email and CAPTCHA handling, testing, deployment and data preservation.

Current worker, pause and submission settings are shown in the dashboard. Uncertain submissions and existing confirmations remain protected. Offline regressions do not establish live employer success.
